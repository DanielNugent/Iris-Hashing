# Iris Hashing

# Install the python deps

# Run

`py script.py`

You can change the eye scan you want to compare to all other scans in the script by passing `compareIrisHashes("S1{ScanNo}{L|R}01", "{ScanNo}_{L|R}")`

examples could be `compareIrisHashes("S1029L01", "029_L")`, `compareIrisHashes("S1001L01", "001_L")` etc
